# Milara · מילארה — Privacy information

**Pre-release notice · September 30, 2026.** Milara is an App Store draft for a proposed parent-guided Hebrew reading practice app. There is **no released Milara app** and no Milara user account, child profile, subscription or app-collected data at this time.

The planned product is intended to let a parent choose Hebrew or English guidance and help a child practice reading Hebrew. Before any release, we will publish a product-specific privacy policy covering the actual implementation: what reading progress is stored on-device or transmitted, any parent or child account, analytics, purchases, retention, deletion, third-party processors and how a parent can contact us. We will not assert that a feature is private or child-safe without verifying the built app. Parents should not submit a child’s name or sensitive information through the public support issue tracker.

For pre-release questions, use [Milara support](milara-support.md). The public issue tracker must not be used to disclose children’s personal information.
