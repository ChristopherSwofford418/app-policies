# KindShift — Privacy Information (Pre-release)

KindShift is a **pre-release concept** for scheduling recurring adult volunteer shifts in small community groups. There is no downloadable app, user account, paid plan, or subscription for KindShift yet. Because no app is running, KindShift currently collects no data through an app. This page is not a claim about a future implementation.

A future product might need organizer and volunteer display names, optional contact details, group/role information, shift sign-ups, attendance and changes to run a shared schedule. Those are **proposed**, not implemented. We will specify the data actually collected, why it is used, service providers, permissions, retention, deletion/export procedures, and any analytics in an updated policy and App Store privacy disclosures **before** release. No public roster, background check, safety certification, donation processing, or service-hours verification is promised here. The intended product is adult-oriented and should not be used to collect children’s names or locations.

For general questions, use the [public support route](kindshift-support.md). A public GitHub issue is visible to others and is governed by GitHub's own privacy practices. **Do not include anyone’s name, email, shift/location details, access code, personal information, or sensitive information in a public issue.**
