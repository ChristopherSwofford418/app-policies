# StaySlate — Privacy Information (Pre-release)

StaySlate is a **pre-release concept** for small short-stay hosts and their existing cleaners to organize property checklists, exceptions and a selective turnover handoff. No downloadable app, user account, purchase, or subscription exists yet. StaySlate currently collects no data through an app because there is no operating app; this is not a privacy promise about a future release.

An implemented service might process an organizer’s display name, property nickname, task status, collaborator invitations, and optional condition notes or photos. It should minimize guest and cleaner information. No calendar integration, access-code vault, end-to-end encryption, security certification, payment processing, or automatic photo redaction is claimed to exist today. Before release, an updated policy and App Store privacy disclosures must identify actual data collected, providers/SDKs, purposes, recipients, retention, sharing permissions, and export/deletion controls. The proposed product is adult/operator-oriented; photos or notes should not include guests, children, keys or access codes.

For general questions, use the [public support route](stayslate-support.md). Public GitHub issues are visible to others and subject to GitHub's own privacy practices. **Do not post property addresses, access instructions, guest/cleaner identities, booking dates, faces, photos or other personal information in a public issue.**
